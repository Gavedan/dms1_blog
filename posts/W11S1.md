## Class Activity

![w3](w3.png) 

For today's class, we were told to recreate a website from our memory and made use of the wireframing tools that were available in figma. From the slides, we learnt that we can be more precise with the tools that are in figma to ensure that things were int he correct place.

After that, we get to see the actual website to create an even more accurate replica and train our skills in figma so that we can do things more efficiently and precisely too.
